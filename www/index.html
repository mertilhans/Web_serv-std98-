webserv

A small HTTP/1.1 server written in C++98, for the 42 webserv project.

Try the mandatory features

  • /old — HTTP redirect (301 → /index.html)
  • /cgi-bin/hello.py?name=webserv — CGI (GET, query string)
  • /does-not-exist — default 404 error page
  • POST /uploads/<filename> — file upload
  • DELETE /uploads/<filename> — file delete

Other servers in this config

  • 127.0.0.1:9090 — api_local (specific IP)
  • <any interface>:9090 — api_public (wildcard, merged socket)
  • 127.0.0.1:9091 — admin_panel, with autoindex and custom error pages
